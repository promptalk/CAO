# CAO

공유마당 등 공개 자료를 수집하고 정리하기 위한 문서형 저장소입니다. 현재는 NotebookLM 활용을 위한 소설 자료와 각 작품의 출처 및 라이선스 정보를 함께 보관합니다.

## 저장소 구조

```text
assets/
└── 노트북LM활용/
    └── 소설/
        ├── 제4원칙/
        │   └── 제 4원칙.txt
        └── 박제/
            └── 박제(剝製) -또 다른 『날개』: 아내의 이야기-.txt
```

## 포함 자료

- `제 4원칙.txt`: 이하늘 작가의 「제 4원칙」 출처 및 라이선스 정보
- `박제(剝製) -또 다른 『날개』: 아내의 이야기-.txt`: 김민재 작가의 「박제(剝製) -또 다른 『날개』: 아내의 이야기-」 출처 및 라이선스 정보

## 사용 방법

1. `assets/노트북LM활용/소설` 아래에서 필요한 작품 폴더를 선택합니다.
2. 각 `.txt` 파일의 출처 링크와 라이선스 정보를 확인합니다.
3. NotebookLM 등 분석 도구에 업로드하거나 참고 자료로 활용합니다.

## 가상회사 운영 프롬프트 실행 순서

아래 프롬프트는 첨부 이미지의 흐름을 텍스트로 정리한 것입니다. 순서대로 입력하면 가상의 팀원 3명을 구성하고, 각 팀원의 관점으로 의견을 낸 뒤 최종 결과물을 만들 수 있습니다.

### 1. 가상 직원 3명 만들기

```text
나는 지금부터 가상의 직원 3명을 두고 가상의 회사를 만들거야.
```

```text
팀원은 아래와 같이 정확히 설정해줘.

직원 A - 기획자
- 역할: 아이디어 생성, 전략 수립
- 성격: 창의적, 낙관적
- 목표: 새로운 방향 제시, 큰 그림 설계

직원 B - 검증자
- 역할: 리스크 분석, 오류 검출
- 성격: 비판적, 논리적
- 목표: 문제 찾기, 현실성 체크

직원 C - 실행자
- 역할: 실제 구현(코드, 문서 등)
- 성격: 실용적, 빠름
- 목표: 결과물 생산
```

### 2. 팀 과제 지시하기

```text
지금 우리는 새로운 텀블러를 기획하고 있어.
MZ세대에게 명확한 텀블러의 브랜드를 기획하자.
```

### 3. 각 팀원의 의견 받기

```text
3명의 팀원들이 지금부터 3명이 모두 한 번씩 의견을 내는 것을 1라운드로 하고,
10라운드 토론을 시작해서 결론을 도출해줘.
```

### 4. 최종 이미지 제작 요청하기

```text
'시제품 텀블러 이미지' 제작을 해줘.
```

## 라이선스

각 자료의 라이선스는 파일 내부에 명시된 원문 출처와 라이선스 표기를 따릅니다. 자료를 재사용하거나 배포할 때는 반드시 해당 파일의 출처 링크와 라이선스 조건을 확인하세요.
